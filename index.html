Go Container Sandbox

Gocker is a production-grade, custom-built Linux container runtime engineered in Go. It directly executes namespace isolation, Cgroup quotas, filesystem jails, and virtual mounts to emulate Docker-like isolation at the kernel interface level.

  • Namespace Virtualization

    Isolates UTS (hostname), PID (process tree), Mount points, and Network adapters through Linux clone() syscall execution flags.

  • Cgroups Resource Policing

    Restricts physical hardware consumption, enforcing memory byte limits and CPU shares directly in cgroups v1 and v2 directories.

  • Chroot Sandboxing

    Prisons the execution process into a locked Alpine rootfs folder, ensuring host directories remain completely invisible.
